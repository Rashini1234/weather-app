# Weather App ☀️🌧️

## Overview 🌍  
The **Weather App** provides real-time weather updates using a public weather API. It displays current weather conditions, including temperature, humidity, wind speed, and a brief forecast. The app features a clean and user-friendly interface, making it easy for users to check the weather quickly. ⚡

## Features ✨  
- 📡 **Real-time Weather Data:** Fetches up-to-date weather information using a public API.  
- 🌡️ **Current Conditions:** Displays temperature, humidity, wind speed, and weather status.  
- 🔄 **Automatic Updates:** Keeps weather data refreshed to provide the latest details.  
- 🖼️ **Responsive Design:** Clean and responsive UI for an optimal experience on any device.  

## Technologies Used 🛠️  
- 🏗️ **HTML5:** For the structure and layout of the app.  
- 🎨 **CSS3:** For styling and making the app responsive.  
- 📜 **JavaScript:** For dynamic content and API integration.  
- 🌐 **Weather API:** To fetch live weather data.
